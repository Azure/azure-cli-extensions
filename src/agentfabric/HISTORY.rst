Release History
===============

1.0.0b1
++++++
* Initial preview release for Azure Agent Fabric using API version ``2026-10-07-preview``.
* Add Agent Fabric, member, and Policy Group create, show, list, update, delete, and wait commands.
* Add AKS attach, show, list, update, detach, and wait enrollment commands.
* Add system-assigned Fabric identity and customer-owned Content Safety connection configuration.
* Add AKS member workloads, ACI SandboxGroup references, and service/target port mappings.
* Add optional Entra agent identity and blueprint metadata for ACI and Agent Fabric Sandbox workloads.
* Add egress trust bundle show and list commands.
